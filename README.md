# CB Mvula

Multidisciplinary designer, developer, and filmmaker based in Warsaw, Poland.

I work across interfaces, web experiences, and moving image, with an interest in work that is useful before it is impressive: clear structure, considered motion, and an honest route from prototype to release.

## Current focus

- Interface quality: hierarchy, responsive behaviour, keyboard use, and reduced-motion consideration
- Commerce discovery: search, filters, and decision-making patterns for product-heavy experiences
- WebGL and motion: using spatial interaction where it helps people explore content
- Connected creative practice: design, code, production, and the thinking that joins them
